# Security Policy

## Supported Versions

This project is actively maintained. Security updates are applied to the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

1. **Email** [security@jordannewell.com](mailto:security@jordannewell.com) with the subject line `Vulnerability: JordanNewell profile`.
2. **Encrypt** your report using the GPG key with fingerprint:

   ```
   67567DC5E7C5353F85F2AF0DAC05D3F3E0EFA32A
   ```

3. **What to include:**
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fix (optional)

**Do not open a public GitHub issue** for security reports.

## Acknowledgment

We will acknowledge your report within **72 hours** and aim to provide a resolution timeline in the initial response.

## Scope

**In scope:**

- Repository configuration and metadata
- GitHub Actions workflows
- Published assets and content

**Out of scope:**

- GitHub platform itself (report to GitHub Security)
- Third-party dependencies and services

Please refrain from public disclosure until a fix has been published.
